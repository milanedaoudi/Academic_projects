# Academic_Projects

Ce dépôt contient plusieurs projets académiques réalisés dans le cadre de cours et travaux pratiques en informatique et systèmes embarqués.

## Projets

### 1. CNN (Convolutional Neural Network)
Le dossier `CNN` contient un premier projet d'implémentation de réseaux de neurones convolutifs (CNN) :
- Implémentation en **C++** pour HLS. 
- Cible matérielle : **FPGA Zybo Z7**.
- Objectif : explorer l'optimisation matérielle pour l'exécution de CNN sur architectures embarquées.

- Implémentation en **C**.  
- Cible matérielle : **RISC-V sur FPGA Artix-7**.  
- Objectif : concevoir un **flot HW/SW complet**, incluant la communication entre processeur et accélérateur matériel, et évaluer les performances de l'exécution de CNN sur une architecture RISC-V embarquée.

### 2. Simulation de plateforme matérielle
Le deuxième projet propose une description d'une **plateforme de simulation hardware** :
- Développé en **C++**.
- Permet de simuler le comportement d'une architecture matérielle complète.
- Utile pour tester des algorithmes et des composants avant implémentation réelle.


## Utilisation
Chaque projet contient un fichier `README.md` propre expliquant :
- Les étapes de compilation.
- L'exécution sur simulateur ou cible matérielle.
- Les exemples de tests fournis.
